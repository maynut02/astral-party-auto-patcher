아스트랄 파티 한글패치 - Windows

설치
1. 게임을 완전히 종료합니다.
2. 이 압축파일의 내용을 사용하는 게임 폴더에 그대로 덮어씁니다.

국제판:
Steam\steamapps\common\Astral Party\8vJXnINT

중국판:
Steam\steamapps\common\Astral Party\8vJXn6CN

3. Steam에서 게임을 평소처럼 실행합니다.
4. Preloader가 현재 설치 경로를 확인해 INT_STEAM 또는 CN_STEAM 패치를 자동으로 선택합니다.
5. 호환되는 최신 한글패치 리소스가 있으면 자동으로 준비한 뒤 적용합니다.

참고
- 최초 실행이라 로컬 Addressables catalog가 아직 없으면 호환성을 확인할 수 없어 원본 상태로 실행될 수 있습니다. 이 경우 게임 리소스 준비가 끝난 뒤 다시 실행하세요.
- 한글패치 리소스는 BepInEx\AstralPartyKoreanPatch 아래에 캐시됩니다.
- 게임 업데이트에 대응하는 한글패치가 아직 없으면 이전 패치를 억지로 적용하지 않고 원본 상태로 실행합니다.

제거
- BepInEx를 이 한글패치에서만 사용했다면 게임 폴더의 BepInEx, winhttp.dll, doorstop_config.ini, .doorstop_version을 제거할 수 있습니다.
- 다른 BepInEx 플러그인도 사용한다면 다음 한글패치 파일/폴더만 제거하세요.
  BepInEx\patchers\AstralParty.DataUnity3dRedirect.dll
  BepInEx\plugins\AstralPartyKoreanPatch\
  BepInEx\AstralPartyKoreanPatch\
